# Independent Review of 34 Skills Classified as Malicious

This directory contains 34 CSV records and 34 individually written English reports. Every included Skill is classified as `MALICIOUS` under a harm-based standard: normal installation, runtime behavior, or an explicit use path can damage the user's host, accounts, or data. The decision does not depend on speculation about the author's subjective intent.

- MALICIOUS: 34

The CSV uses a UTF-8 BOM for spreadsheet compatibility. Each report distinguishes static reconstruction, isolated testing, and live observation; dangerous actions that were not executed are never described as completed events.

The package contains reports only. It does not contain the original live or potentially harmful Skill samples.
